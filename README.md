## Deskripsi

Aplikasi pengelolaan menu kantin berbasis Laravel dan MariaDB.
Aplikasi menyediakan fitur CRUD, pencarian, filter kategori,
validasi input, serta pengelompokan status harga.

## Menjalankan Aplikasi

1. Jalankan Laragon.
2. Aktifkan MariaDB.
3. Atur konfigurasi `.env`.
4. Jalankan `php artisan config:clear`.
5. Jalankan `php artisan serve`.
6. Buka http://127.0.0.1:8000/menu.
